## 🎯 Sobre este repositório

Este repositório reúne meu **portfólio executivo e técnico** como **Administrador de Banco de Dados Oracle (DBA)**. Aqui você encontra documentos voltados para **Gestores e CIOs**, meu **Programa de Formação Continuada** em tecnologias Oracle, e projetos práticos desenvolvidos em **IA generativa** (Imersão Alura + Google Gemini).

O objetivo é apresentar, de forma transparente, a maturidade técnica, a visão estratégica de negócio e o compromisso com aprendizado contínuo que ofereço a equipes de tecnologia e lideranças executivas.

## 🤖 Projeto Técnico — Imersão IA (Alura + Google Gemini)

Além dos documentos executivos, este repositório contém os notebooks desenvolvidos durante a **Imersão de Inteligência Artificial** promovida pela Alura em parceria com o Google, utilizando a API do **Gemini** e bibliotecas de ciência de dados em Python.

**Notebooks incluídos:**
- 📓 IA5!.ipynb — Exercícios práticos da imersão de IA, exploração da API Gemini.
- 📓 Untitled19.ipynb — Atividades complementares de IA generativa.
- 📓 _O_Seaborn_é_uma_biblioteca.ipynb — Análise e visualização de dados com Seaborn e Pandas.
